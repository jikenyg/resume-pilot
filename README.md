# ResumePilot · 简历助手

**把简历保存一次，在网申表单中按需填写。**

ResumePilot is a Chrome / Edge extension for resume form filling, with local field matching and optional DeepSeek assistance.

基于 Manifest V3 的浏览器扩展，使用原生 JavaScript、HTML 和 CSS，无需构建。支持本地规则匹配、网页资料预检、多段经历选择，以及需要人工确认的 AI 补填。当前版本：**0.4.1**。

## 功能

- **简历编辑器**：管理基础资料、教育、工作、实习、项目、获奖、语言和家庭成员等集合；首次使用为空白。
- **预览与填写**：先预览识别结果、选择经历条目，再将已保存资料填入当前页面。
- **网页预检**：导入 HTML/TXT 或检查当前页，列出缺少资料、格式问题、动态控件和人工处理项，并定位到对应编辑字段。
- **AI 点选 / 选区补填**：选择一个文本框或框选区域，生成建议、核对后写入，可重试失败项。
- **站点适配**：包含 Hotjob / Ant Design、国家管网、Element Plus 招聘表单、Moka 和部分北森 Phoenix 组件。
- **内嵌页面选择**：选择实际承载表单的 frame，可下载当前表单结构到本机排查。
- **本机诊断**：查看填写结果，可选本机反馈服务保存诊断。

## 安装

1. 下载本仓库 ZIP 并解压，或用 Git 克隆仓库。
2. 打开 Chrome 扩展管理页（地址栏输入 `chrome://extensions/`），或 Edge 的 `edge://extensions/`。
3. 启用「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的项目根目录，固定「简历助手」图标。

运行扩展不需要 Node.js、npm 或 API Key。更新源码后重新加载扩展，并刷新招聘网页。

## 快速开始

1. 打开扩展 → **编辑简历**，录入真实资料并保存。空白模板可以创建各类经历的空条目，按需增删。
2. 打开招聘网站的实际编辑表单。存在内嵌页面时，在弹窗选择目标页面。
3. 点击 **检查本页缺什么资料**，补齐所需资料并重新检查。
4. 使用 **预览识别** 核对映射；存在多段经历时先选择对应条目。
5. 点击 **一键填充本页**，阅读结果并核对网站实际值。支持的站点适配流程优先补空白字段；通用流程也应先预览再操作。
6. 未覆盖的文本或区域可用 AI 补填。附件上传、声明、最终保存和投递由本人完成。

## 可选：DeepSeek AI

在编辑器的 AI 设置中填写自己的 API Key 并选择模型。全页 AI 兜底需开启对应开关；点选 / 选区为手动发起的流程。

- API Key 和简历保存在当前浏览器的 `chrome.storage.local`；公开源码不包含真实密钥或预置个人简历。
- 本地规则填写不调用模型。AI 请求会发送字段说明、可选项等上下文至 DeepSeek；允许发送完整简历后，简历也会发送。
- 点选 / 选区生成需要允许发送完整简历。全页兜底未开启该授权时只发送字段目录。
- 建议写入前请核对；模型可能出错，缺失事实应自行补充。AI 调用可能产生服务商费用。
- 当前服务地址固定在 `background/service-worker.js`，为 DeepSeek 的 chat completions 接口。

## 隐私与权限

| 权限 / 数据 | 用途 |
| --- | --- |
| `storage` | 本机保存简历、设置、模板和诊断 |
| `activeTab`、`tabs`、`scripting` | 获取当前页、识别 frame 并向目标页发送操作 |
| `<all_urls>` | 在不同招聘网站注入表单识别脚本；可在浏览器中按需限制站点访问 |
| 简历字段 | 本地匹配用于填写；点击填写后数据会进入招聘网站表单 |
| API Key | 调用 AI 时在请求授权头中发送给 DeepSeek |
| 诊断 / 网页导出 | 保存在本机；标签、路径、选项或 HTML 仍可能带有个人信息，分享前需检查 |

扩展无需开发者账号或配套云端服务。AI 服务与招聘网站会接收用户明确操作发送的数据。浏览器存储并非专用加密保险箱，请勿共享包含设置的浏览器配置或导出文件。

`.gitignore` 排除了本地备份、反馈记录、密钥文件、环境配置、文档附件和测试截图。私人网页快照与个人资料请放在 `.private/`、`snapshots/` 或 `local-data/`；不要把密钥写进源文件。提交前仍应检查暂存内容。

## 兼容范围与限制

| 场景 | 当前范围 |
| --- | --- |
| 原生文本、下拉、单选、复选、部分日期 | 已有填写与读回检查，具体支持取决于所用流程 |
| Hotjob / Ant Design | 区块和条目映射、部分动态控件、已适配区块的条目补建 |
| 国家管网 / Angular | 展示态预检与部分原生控件；实际编辑弹窗仍需验证 |
| Element Plus 招聘表单 | 已适配结构中的文本、下拉、日期与条目新增；复杂级联需人工处理 |
| Moka / Sugar UI | 字段映射、普通控件及有明确弹层归属的下拉 / 年月选择 |
| 大唐招聘 | 教育准备检查和 frame 定位；专用编辑、新增、保存尚待适配 |
| 多步表单、附件、验证码、签名、协议 | 逐页核对或人工处理；不自动提交申请 |
| 关闭的 Shadow DOM、未知自定义组件 | 可能无法识别或操作 |

**识别到字段不等于填写成功，测试通过也不代表所有招聘网站兼容。** 动态加载、联动清空、远程字典、页面更新和服务端校验可能要求人工处理。详见 [站点适配说明](docs/three-sites-preflight.md)。

## 开发与测试

需要 Node.js 22+ 和已安装的 Microsoft Edge：

```sh
npm install
npm test
```

Playwright 只用于开发测试。测试启动独立无头浏览器，使用合成资料和模拟 AI；不会读取日常浏览器配置或调用真实模型。详见 [tests/README.md](tests/README.md)。

可选本机反馈服务：

```sh
node feedback-server.js
```

服务监听 `127.0.0.1:3742`。编辑器中开启自动上报并检测连接后，诊断写入被 Git 忽略的 `feedback/inbox/`。

## 目录结构

```text
resume-pilot/
├── manifest.json              # 扩展清单
├── background/                # AI 请求与本机反馈
├── content/                   # 页面扫描、控件操作、AI 点选和选区
├── shared/                    # 数据模型、关键词、预检与站点适配
├── popup/                     # 扩展弹窗与 frame 路由
├── options/                   # 简历编辑与设置
├── assets/                    # 扩展图标
├── docs/                      # 站点能力与边界
├── tests/                     # 合成页面回归测试
├── tools/                     # 测试运行器与页面检查工具
└── feedback-server.js         # 可选本机诊断服务
```
