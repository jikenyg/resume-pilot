# 中信银行校园简历适配（0.5.0）

## 依据与范围

本次用户提供的是中信银行外层门户 HTML。实际简历位于 `iframe#myFram`，路径为 `/CustStyle/zpmhys/addSchoolResume4.html`。外层的登录、注册、密码与验证码不属于简历。

已读取 [官网公开校园简历模板](https://job.citicbank.com/CustStyle/zpmhys/addSchoolResume4.html)，离线样本位于 `tests/fixtures/citic-school.public.html`。文件没有用户账户资料；测试不加载其中的脚本或远程资源。

按 `way-data` 业务字段、所属区块及条目索引对应资料，避免同名“姓名”“亲属关系”“学校”误填。真实字典由站点加载，模板不含字典值，因此运行时仅选择实际出现且唯一匹配的选项。

## 已实现

- 自动定位中信校园简历 iframe；外层预检明确说明缺少内层表单，拒绝向登录窗口填写简历。
- 基本资料、薪酬、教育、实习、在校职务、工作、项目、语言、资格认证、计算机技能、培训、奖惩、家庭、其他重要信息与自我评价的字段对应。
- 普通输入、完整日期、原生及 Bootstrap selectpicker 字典选择、省市及专业／学位等分级选项。已有上级选项相符时只补下级；不相符时保留并报告。
- 按明确的添加按钮补足已保存经历；未生成可识别条目就停止。重复填写不重复新增，每区块最多自动处理 30 条。
- 教育按高中到最高学历升序填写，保留本地条目索引；已有学校或学历不符时保留整条。没有高中资料时先报告。
- 奖惩区按竞赛获奖、荣誉称号顺序合并读取，仍定位回各自编辑字段。
- 缺少父母信息、日期格式、重复最高学历标识等进入预检。声明类资料空白时不推断“否”。
- 写入前检查变化和已有内容，写入后重新读回；联动清空及页面校验失败不算成功。

## 请在简历编辑端补充

预检可点击“去补充”进入对应字段。字段默认空白，保存后重新检查。

- **紧急联系人**：姓名、电话、与本人关系；电话国家／地区代码、生育状况、获取信息渠道。
- **薪酬**：“中信：期望税前年薪（万元）”。例如真实期望年薪 25 万元，填 `25`；不会将月薪直接填入。
- **教育**：高中学校和完整起止年月日、学习形式／方式、定向委培、院系、专业类别、学位类别和学位、授予国家、毕业方式、第二学位情况。只能一条最高学历；最高学位等网页校验仍须核对。
- **分级选项**：按层级用 `/` 分隔，如 `省/市`、`省/市/区`、`专业大类/细类`；学位使用“中信：学位类别”与“学位”两个字段。
- **经历细项**：实习部门、工作用工形式／职级／行政职务／离职原因、项目成果、培训经历、语言证书颁发机构、证书成绩、奖惩类别和单位。
- **家庭成员**：关系、姓名、年龄、电话、单位／部门／职务、境外身份及国家。官网要求父母均登记，有配偶和子女也需填写；事实由本人确认。
- **中信声明**：中信或监管机构亲属、业务合作、海外经历、境外身份、违规犯罪、刑责／留置、失信、从业禁止行为、机关谈话、重大病史等分别保存，仅用本人明确填写的内容匹配。

## 使用与验收边界

1. 重新加载本目录扩展，确认 0.5.0，刷新招聘页及编辑简历页。
2. 打开中信“我的简历”，等待加载；插件目标页面应为“中信银行校园简历”且不带“外层”。
3. 检查本页缺什么资料 → 补充真实资料 → 保存简历 → 回网页再次检查／填写。
4. 核对字段，手动上传照片和附件，分别点击网站各区块保存。

本轮完成公开模板和离线控件测试，**未登录用户账户验证服务器保存**。插件不点击保存、撤销投递或提交申请。动态字典无匹配、只读字段、学校需选“其他”、额外条件项和服务器限制会留下待处理项，不能仅凭模板保证申请必然完成。学校或证书无匹配时，先手动选“其他”，再运行填写补具体名称。

教育检查面板可切换大唐与中信，中信预检自动切换到中信规则。
