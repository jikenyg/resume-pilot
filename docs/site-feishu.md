# 飞书招聘 / 商业卫星简历适配

版本：0.5.4。依据 2026-10-01 提供的“中国航天科技集团商业卫星有限公司”简历编辑页，以及该页公开 ATSX 组件代码。

## 问题和修复

| 页面特点 | 适配行为 |
| --- | --- |
| 实习、项目、作品、获奖、语言、社交账号默认折叠 | 有对应资料时点击各自添加按钮，等待新条目出现，再逐条填写 |
| 多条经历的字段 ID 不一定连续 | 按网页条目顺序对应简历条目，用绑定字段区分学校、公司、职位和描述 |
| 学校是可自由输入的组合框，学历是普通下拉 | 学校通过输入事件提交；学历等只选择本控件所属列表中的唯一匹配项 |
| 起止时间只展示年月标签，内部 input 用于键盘焦点 | 点击真实年份和月份选项，不把日期塞进隐藏 input；支持完整年月和明确“至今” |
| 手机号码来自登录账号 | 只读核对；与简历不同会提示，不改账号信息 |
| 工作经历可勾选“没有工作经历” | 该操作会删除条目，保留给本人操作；不因简历暂缺资料而推断没有经历 |
| 自我评价使用租户自定义数字 ID | 只在“自我评价”区块按同名标签对应，不猜测其他自定义问题 |

获奖区块依次读取竞赛获奖和荣誉称号；语言“掌握程度”使用独立 proficiency 字段，不拿四六级考试等级代替。作品和社交账号增加独立的可编辑资料集合。工作、实习和项目分别取各自资料，已有冲突条目停止补填。

教育/工作/实习/项目的日期按网页年月精度使用真实日期；获奖时间按日期控件的年/月/日提示处理。不补造缺失月份或日期，不换算、不生成经历内容。

## 使用

1. 重新加载扩展并刷新招聘页，目标页面应识别为“飞书招聘 / 商业卫星”。
2. 在编辑简历中保存真实的多条教育、工作、实习、项目、获奖和语言掌握程度；如需填写作品和社交账号，补充新增集合。
3. 先预览，再填写。预览不会点击添加；填写时自动展开有资料的区块。
4. 对已错填的字段，核对报告后清空相应条目再重填。手机号、“没有工作经历”、附件上传和最终保存由本人在网页核对。

## 验证与限制

- `node tests/site-feishu.cjs` 使用脱敏后的真实 DOM、合成资料和独立无头 Edge，验证折叠区块展开、非连续条目 ID、学校自由输入、下拉归属、年月/至今、重复运行、冲突保护、只读账号和正常插件入口。
- 可附加原 HTML 路径核对结构；使用 DOMParser 惰性解析，不执行快照中的网页脚本。
- 远程搜索返回的学校、下拉选项和服务端保存校验仍需实页核对。未出现在已知结构中的自定义字段会报告待处理，不由通用匹配猜填。
- 原始 HTML、个人信息和下载的网页脚本不提交到仓库。测试夹具中的手机号为合成值。
