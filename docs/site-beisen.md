## 本次问题与修复

| 原问题 | 修复方式 |
| --- | --- |
| 邮箱填生日、体重填身高、专业课程填专业名称 | 只读取当前表单项标签，按区块和字段精确映射 |
| 家庭成员和证明人使用本人姓名、手机号、政治面貌 | 家庭成员、实习证明人、工作证明人各用自己的结构化字段，缺失时留空并报告 |
| 公司与职位、职务与日期、证书名称与种类拼接 | 每个字段只取一个对应来源，不拼接相邻资料 |
| 论文期刊填入整段论文介绍，年度/期次填作者顺序 | 新增独立期刊、期刊级别、期次和作者顺序字段；检查已知字数上限 |
| 教育等多条经历只填一条或串到其他区块 | 按条目填写，使用各区块添加按钮展开；保留已有内容，冲突条目停止补填 |
| 性别等单选漏填 | 识别 Phoenix 自定义单选，并验证选中状态 |
| 日期、地区、字典选择未提交 | 日期通过日历输入提交；地区按路径逐级导航；兼容立即提交和组件内确认按钮；填写后读回 |
| 重跑时旧错值看起来已经完成 | 在报告中提示已有内容与资料的冲突，用户核对、清空后再填 |

## 使用

1. 在 Edge/Chrome 扩展管理页重新加载 `D:\jianLiZhuShou` 中的简历助手，再刷新招聘网页。
2. 打开“编辑简历”，补齐实际有的资料。特别检查高中经历、各学校课程和城市、证明人、论文结构化条目、证书成绩、家庭成员及近亲属声明。
3. 插件的目标页面应显示“北森 / 中央结算 Phoenix”。先检查本页缺什么资料，再执行填写。
4. 对以前已经错填的内容，依据预检和填写报告核对后清空对应字段再重填。资料与网页条目不一致时，整条经历停止补填，避免进一步混填。

原有简历资料不会自动迁移、拆分或补造。`base.paper` 的整段文字不会自动变成某篇论文的期刊；语言考试分数不会进入另一张证书；爱好不会自动代替特长。近亲属声明没有默认答案。
