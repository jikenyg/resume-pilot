# 大唐教育准备与 frame 定位

## 范围

弹窗识别 frame，将命令发送到选定 frame / document；多个候选需要选择，导航后旧选择失效。外层导航不作为实际表单。

## 当前行为

教育检查覆盖高中缺失、学校 / 学历 / 日期 / 城市、日期有效性与重复最高学历。补充高中只创建空白条目，用户填写后需保存。导出表单代码保存在本机，仍可能含个人资料。

## 限制

尚未完成大唐专用编辑、新增和保存。需要实际编辑表单结构继续验证；准备检查不等于完整必填清单或完整自动填写。

预检反映当前简历和页面状态，资料变更后需重新检查。不推断缺失事实，不根据默认选项生成身份、家庭或资格声明。

## 验证

安装开发依赖和 Edge 后运行 node tests/datang-education.cjs。测试使用合成资料和独立浏览器。可按 tests/README.md 传入本机快照作静态解析；快照请放在被忽略的目录，不提交到仓库。测试不能代替真实网站和服务端验证。
