# Hotjob 扩展招聘表单

适配依据：2026-10-01 提供的“简历操作”网页源码。快照未保留公司名称及地址，因此按“基本信息 / 英语能力 / 曾用名 / 分公司调剂”等结构识别，不猜测公司名称。

## 为什么之前大片空白

原 Hotjob 适配认识“个人基本信息、教育信息、语言能力”，本模板使用“基本信息、教育经历、英语能力”，还包含独立实习经历、两级技能类别、家庭电话等字段。旧字典没有对应关系，很多字段被跳过。院校和专业还各有一个隐藏备用输入框，不能当作两个需要填写的字段。

## 本次实现

- 新增独立 `hotjob-extended` 适配；保留原 Hotjob、北森、中信、管网、Moka 和 Element Plus 的识别规则与字段映射。
- 按区块、条目编号、本项标签取值；个人信息、家庭成员、工作与实习分别对应。
- 教育按学历从高中起排列，工作按开始时间由近到远排列；有对应资料时点击各区块新增按钮，再重新扫描字段。
- 英语能力只取英语记录；其他外语独立处理。技能增加“上级类别、使用时间、所属区块”，默认归入计算机技能，需要填写其他技能时明确选择对应区块。
- 地区和技能通过两级下拉分别提交；学历与英语等级支持明确等价别名；院校、专业通过弹出的选择器精确选择；日期使用日历组件输入提交。
- 选择学历后出现的新字段会再次扫描。上传、未知字段、字典未加载及已有内容冲突会在报告中说明。
- 曾用名、亲属任职、个人声明等信息不会凭空补造。已有错误内容需要用户核对清空后再填。

## 使用与验证

更新扩展后重新加载扩展，再刷新招聘页。目标页面显示“Hotjob / 扩展招聘表单”。先检查缺失资料，再填写。

`node tests/site-hotjob-extended.cjs` 使用实际表单的脱敏结构和合成资料，检查 101 项可见字段及未展开区块，并验证隐藏输入排除、教育展开、条件字段、家庭隔离、英语筛选、技能/地区联动和选择器提交。测试可以传入 HTML 快照路径作惰性结构比对。

没有在真实账户提交申请。远程字典内容、新增后出现的未知字段及服务器校验仍以网站为准；未找到唯一选项时会保留并提示。
