# Hotjob / Ant Design

## 范围

按区块、标签和条目索引映射基础资料、教育、家庭、技能、项目等，预检与填写共享映射。区分本人和家庭成员、学历和学位、等级和分数。

## 当前行为

支持普通文本、单选、已识别英语考试复选、精确匹配的 Ant 下拉、可提交日期、部分逐级地址和已适配区块的条目补建。保护已有值并最终读回。

## 限制

照片、附件、未展开区块及未知学校 / 专业组件需人工处理或进一步适配；不能仅凭 HTML 保证申请完成。

预检反映当前简历和页面状态，资料变更后需重新检查。不推断缺失事实，不根据默认选项生成身份、家庭或资格声明。

## 验证

安装开发依赖和 Edge 后运行 node tests/page-audit.cjs。测试使用合成资料和独立浏览器。可按 tests/README.md 传入本机快照作静态解析；快照请放在被忽略的目录，不提交到仓库。测试不能代替真实网站和服务端验证。
