# Moka / Sugar UI

## 范围

shared/site-moka.js 覆盖基础、意向、教育、工作、实习、项目、语言、自我描述与获奖。

## 当前行为

支持普通控件、有明确归属的下拉 / 年月选项和符合既定结构的条目新增。项目角色、简短职责和详细职责分别维护。

## 限制

未展开弹层属于动态待验证；头像和禁用字段需人工核对；不能将搜索框文本当作选项提交成功。

预检反映当前简历和页面状态，资料变更后需重新检查。不推断缺失事实，不根据默认选项生成身份、家庭或资格声明。

## 验证

安装开发依赖和 Edge 后运行 node tests/site-moka.cjs。测试使用合成资料和独立浏览器。可按 tests/README.md 传入本机快照作静态解析；快照请放在被忽略的目录，不提交到仓库。测试不能代替真实网站和服务端验证。
