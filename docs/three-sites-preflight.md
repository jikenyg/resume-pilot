# 站点预检与填写

预检和填写使用同一站点适配器和映射。报告区分资料缺失、格式问题、动态待验证、人工处理和未映射。状态可能重叠，不能相加作为成功率。公开版不包含个人简历或私人网页快照，不提供基于某个人资料的缺失统计。

## 使用

1. 在编辑器导入 HTML/TXT，或在招聘网页检查本页。
2. 从“去补充”定位字段，按真实情况编辑。
3. 保存后重新检查，再预览和填写。
4. 核对网站实际值，手动处理上传、协议及最终保存 / 投递。
