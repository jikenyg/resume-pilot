# 招聘表单 / Element Plus

## 范围

shared/site-recruit2.js 覆盖基础、教育、家庭、亲属声明、技能、工作 / 实习、社会实践、奖励和论文。

## 当前行为

支持已识别结构的文本、唯一匹配的真实选项、可提交日期及明确的新增按钮。学历与学位、奖项级别与性质分别映射；条目标识冲突时停止补填。

## 限制

照片、协议、地区和专业级联需人工处理。远程字典、条件字段与最终保存尚需真实页面验证。

预检反映当前简历和页面状态，资料变更后需重新检查。不推断缺失事实，不根据默认选项生成身份、家庭或资格声明。

## 验证

安装开发依赖和 Edge 后运行 node tests/site-recruit2.cjs。测试使用合成资料和独立浏览器。可按 tests/README.md 传入本机快照作静态解析；快照请放在被忽略的目录，不提交到仓库。测试不能代替真实网站和服务端验证。
