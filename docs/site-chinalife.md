# 中国人寿简历适配

适配依据：2026-10-01 提供的《中国人寿招聘官网》北森 Phoenix 表单源码。版本：0.5.3。

## 问题和处理

这份表单使用“个人基本信息”“工作/实习经历”“专业论著”等名称，与中央结算模板不同。原适配没有命中，通用匹配无法准确区分各区块的同名字段。

- 新增中国人寿独立识别和字段映射，覆盖快照中 15 个区块、91 个表单项，其中 84 项有精确资料来源，4 个上传项和承诺、签名、填表日期由本人完成。
- 工作和实习依次读取各自集合，在网页同一区块逐条展开；获奖和荣誉同样保留各自来源。教育经历保持编辑简历中的顺序，空记录不生成额外条目。
- 姓名、日期、联系方式按区块和条目隔离，家庭成员不会继承本人信息。论文名称、刊物、角色、摘要分别填写，不把论文整段文字复制到多个栏位。
- 复用已有 Phoenix 下拉、级联地区、日期及单选操作，并读回验证。“是否服从调剂”将保存的“是/否”对应到“接受/不接受”。
- 填写过程中重新识别控件，处理页面替换输入框和新增条件字段；未提供结构的条件字段列入待处理报告。
- 已有值不覆盖；经历中有不一致内容时停止补填该条，防止混入另一段经历或另一位成员的信息。

原中央结算、Hotjob、中信等适配继续保留。共享的是控件操作，中国人寿使用自己的区块映射和选项转换。

## 使用

1. 重新加载扩展，再刷新中国人寿招聘网页。页面检查应识别为“中国人寿 / 北森 Phoenix”。
2. 在“编辑简历”补充真实资料：加入党派时间、是否全日制/最高全日制学历/主修、家庭成员出生日期、论著角色及摘要、项目级别、资格证书选项等。
3. 中国人寿的亲属任职/退休、县级公司意愿、奖学金、学生干部、处理记录和境外身份问题使用独立声明字段，未明确提供答案时留空。基本信息与附加信息中的重复亲属问题读取同一答案。
4. 期望待遇单独填写“万元/年”数字；不把月薪或中信的税前年薪字段直接复制过来。“具有资格证书”按网页实际选项补充，不能仅凭证书名称猜测。
5. “爱好及特长”“自我评价及求职目标”读取相应合并栏；“优势与不足”单独填写。项目经历对应网页科研项目，请核对这些经历适用本次申请；标为“其他技能”的记录不会进入计算机技能。
6. 先检查缺项再填写。旧错值需核对、清空后重填；证件照、生活照、附件、本人承诺、签名及最终保存由本人完成。

资料只新增编辑字段，不迁移、猜测或改写原简历值。日期需要真实完整年月日，不自动补“1 日”。

## 验证范围

`node tests/site-chinalife.cjs` 使用提供页面的脱敏 DOM 和独立无头 Edge，测试来源隔离、多条展开、单选/日期/地区、控件重建、重复运行、缺失声明、薪资单位、非法日期、已有内容冲突及原中央结算路由。可传入本地原始 HTML 路径额外比对结构，原网页脚本不会执行。
