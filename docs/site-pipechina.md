# 国家管网 / Angular

## 范围

shared/site-pipechina.js 覆盖基础、教育、管网混合经历、家庭、语言、获奖、证书和附件占位。

## 当前行为

展示态字段仅作预检。已展开、可定位的原生文本、单选和 select 可填写，保留已有值并核验。混合经历单独维护，不自动从其他集合拼接。

## 限制

完整编辑弹窗尚待验证。修改 / 新增、Angular 复杂组件、级联、只读日期和上传需人工处理或进一步适配，不自动点击保存或投递。

预检反映当前简历和页面状态，资料变更后需重新检查。不推断缺失事实，不根据默认选项生成身份、家庭或资格声明。

## 验证

安装开发依赖和 Edge 后运行 node tests/site-pipechina.cjs。测试使用合成资料和独立浏览器。可按 tests/README.md 传入本机快照作静态解析；快照请放在被忽略的目录，不提交到仓库。测试不能代替真实网站和服务端验证。
